# Piyush Assudani — portfolio

A scroll-driven portfolio set in the Thar desert around Balotra. No backend, no database: all content is hardcoded in
`src/content.ts`, taken from Piyush's own story, piyushassudani.in and the live client sites.

**The sky follows the visitor's clock.** Sunrise, day, sunset, evening and night are worked out from the local time
(with seasonal sunrise/sunset times for Balotra's latitude), and the theme turns dark once night falls. The pill in the
header lets visitors preview any time of day; the choice lasts only for that browser session.

The 3D world (Three.js) is scenery: dunes, sun and moon, stars, kites, chhatris and sky lanterns, with the camera flying
from chapter to chapter. All content is crisp HTML on top of it.

| # | Chapter | What's there |
|---|---------|--------------|
| 00 | Home | name, intro, live greeting by time of day |
| 01 | The story | five beats: childhood, the first ₹500 client, door to door, the Play Store, today |
| 02 | Toolkit | a draggable 3D orbit of tools, filtered by area (kites fly behind) |
| 03 | Apps | 3D coverflow of the real app screens: Atteni, PyPocket, Perfect Bandhan, "Upcoming soon". Click/tap for the full story |
| 04 | Client work | 18 sites on a turning 3D arc (scroll on desktop, swipe on mobile). Click for the summary |
| 05 | Assudani Group | the company as a 3D structure: group → two divisions → three products, linked to assudanigroup.online |
| 06 | Kind words | all 8 reviews from the live site (sky lanterns behind) |
| 07 | About me | photos fanned out in 3D, the bio, facts, and the full name |
| 08 | Contact | form that opens WhatsApp or email, no backend |

**Mobile is its own layout** (`src/device.ts`): the story becomes stacked cards, the 3D apps and client galleries
are swiped instead of scroll-pinned, summaries open as bottom sheets, and the 3D world is lighter with native scrolling.

**Performance:** no post-processing or shadows, a lighter terrain, no per-frame allocations, and the render resolution
drops automatically on slow devices.

## SEO

Generated at build time from `src/content.ts` by `seo.ts`, so it never drifts from the page:

- JSON-LD graph: ProfilePage, Person (with full name), Organization (Assudani Group), the apps as SoftwareApplication, and the client sites as an ItemList
- a `<noscript>` copy of the whole story for crawlers and AI agents that don't run JavaScript
- `sitemap.xml` (with image entries), `robots.txt` (search engines and AI crawlers allowed), `llms.txt`, `site.webmanifest`
- Open Graph and Twitter cards with `og-image.jpg`, canonical URL, geo tags, icons

Separate indexable pages (generated by `pages.ts` into `public/`, so don't edit those HTML files by hand): `/about/`, `/work/`, `/apps/`, `/apps/atteni/`, `/apps/pypocket/`, `/apps/perfect-bandhan/`, `/contact/`. Each has its own title, description, breadcrumbs, structured data and linked images, and they all link to each other so Google can show them as sitelinks.

Policies: `privacy.html` and `terms.html` (static pages, linked in the footer and sitemap).

Every image ships as WebP with a JPEG fallback (`<picture>`).

## Run

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # static site in dist/ — deploy to Cloudflare Pages, Netlify or Vercel
```

## Editing

- Text, story, apps, client summaries, links: `src/content.ts`
- Images: `public/media/` (`work/` site screenshots at 1280×800, `apps/` phone screens at 600×1300, `photos/`)
- Time-of-day logic: `src/daylight.ts`; sky colours: `THEMES` in `src/scene/env.ts`; page colours: tokens at the top of `src/styles.css`
- Atteni and PyPocket phone screens are currently screenshots of their websites. Drop real app screenshots into
  `public/media/apps/atteni.webp` / `pypocket.webp` (same names) to replace them.

Stack: TypeScript, Three.js, GSAP, Lenis, Vite.
